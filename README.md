🐱 哈基米 (Hajimi)
===============

**没有人知道哈基米是什么意思** 下一代跨平台隐私通信协议 ------ 让加密消息混入在普通对话中。

📖 项目简介
-------

**哈基米** 是一个基于浏览器的端到端加密（E2EE）通信增强工具。它旨在解决传统社交软件（张X龙, Facebook, SMS 等）无法保证绝对隐私、且 PGP 密文特征过于明显易被拦截/限流的问题。

通过哈基米，你可以将敏感信息转化为**看似普通**的文本或短链接，在任何社交平台上自由分享，只有预期的接收方可以解锁。

✨ 核心特性
------

-   **现代加密：** 弃用臃肿的 PGP 体系，全面采用新思维去考虑实战问题。

-   **抗风控混淆：** 支持将密文编码为 Emoji 或古诗词，规避社交平台的过滤与 Shadow Ban。

-   **可本地使用：** 前端+弱后端项目，代码公开。密钥对生成、加密、解密可完全在浏览器本地完成。除了用户体系和长密文，为了用户体验需要后端协同，其他部份均在前端无网完成。

🛠 页面功能详解
---------

### 🔐 `/encrypt` 加密工坊

-   **多模式输出：**

    -   **短密文模式：** 针对短消息，支持 Emoji 编码或 Base58 压缩，适合短信/私信情形。

    -   **长密文+链接模式：** 针对长篇大论，生成唯一识别码并存储加密后的 Blob，有密钥的自动解密。

-   **接收方选择：** 支持从本地通讯录快速检索已添加的朋友。（联网功能）

### 👤 `/u/{userHandle}` 身份主页 *联网功能*

-   **去中心化身份：** 展示用户的公钥快照。

-   **一键互关：** 将对方公钥保存至浏览器本地存储（IndexDB），建立信任链路。

### ⚙️ `/my` 密钥中心

-   **身份管理：** 自定义头像与 Handle，这些信息仅作为本地/分享时的标识。

-   **全生命周期控制：** 支持密钥对的生成、备份（助记词/JSON）、恢复，以及紧急情况下的密钥吊销。

### 📖 `/m/{messageId}` 长文分享 *联网功能*

-   **中转站：** 用于承载社交平台无法容纳的长密文。

-   **本地解密：** 后端不进行逻辑运算，仅提供加密 Blob，由访问者的本地密钥进行解密渲染。

### 🆕 `/register` 极速入驻 *联网功能*

-   **无感知开户：** 采用类似硬件钱包的助记词方案，一键生成符合现代安全标准的 X25519 密钥对。

🚀 技术栈
------

-   **Frontend:** React + Vite + TypeScript

-   **Styling:** Tailwind CSS

-   **Crypto:** [noble-curves](https://github.com/paulmillr/noble-curves) (High-audit cryptographic primitives)

-   **Storage:** IndexedDB (Local) + Supabase (Optional for Link Mode)
